# BUSINESS OPS BACKLOG — the operating systems a solo consultancy needs

Status of each operational system for Opportunity Designed: HAVE / PARTIAL / GAP, and the next step. Turn any
PARTIAL or GAP into Tasks on the master board. Update as things move.

- Finance - bookkeeping/accounting: PARTIAL. Have invoicing template. GAP: a real books system (QuickBooks
  free tier or similar), expense capture, quarterly P&L, estimated-tax set-aside. Next: pick the tool, set up
  chart of accounts, monthly close routine.
- Invoicing + payment collection: PARTIAL. Invoice template exists. Next: a payment link + a reminder
  sequence template + a Notion "Invoices" tracker (issued / due / paid).
- Contracts + e-sign: PARTIAL. MSA/NDA drafts exist, need attorney review before first client. GAP: an e-sign
  flow (free tier) and a signed-contract store/tracker with renewal dates.
- Client lifecycle: PARTIAL. Have the Blueprint delivery + portal. GAP: a standard onboarding packet, a
  closeout/offboarding checklist, and a testimonial+referral ask built into closeout.
- CRM / pipeline: PARTIAL. HubSpot free capturing leads. Next: define pipeline stages, a follow-up cadence,
  and a weekly pipeline review (ties to the weekly review automation).
- Credentials + security: GAP. Next: a password manager, 2FA on everything, and a single access list (who/what
  can reach which account) kept out of the repo.
- Data / backup / recovery: PARTIAL. The git hub + daily reconcile cover files. Next: a scheduled Notion export
  and a one-page recovery runbook (what to restore, in what order).
- Analytics / reporting: PARTIAL. GA4 + GSC + HubSpot collect data. GAP: a monthly KPI snapshot (traffic,
  inquiries, bookings, pipeline) in one place.
- Insurance: GAP. Next: check general liability / professional (E&O) for a solo consultant.
- Brand asset governance: PARTIAL. DAM + source-file tracking exist. Next: usage rules + a periodic asset audit.
- Email deliverability: PARTIAL. ImprovMX + send-as live. Next: periodic SPF/DKIM/deliverability check;
  finish the Cal.com addie@ verification blocker.
- SOP library: PARTIAL. These protocol docs are the start. Next: short runbooks for deploy, publish content,
  file a lead, close a client, monthly close.
- Capacity / time planning: GAP. Next: availability + WIP limits + pricing-to-capacity so the calendar does not
  oversell.
- Subscriptions / tools ledger: GAP. Next: one list of every tool, tier, cost, renewal date (enforces the
  free-tier discipline and catches surprise charges).
- Testimonials / proof engine: PARTIAL. Proof Bank exists. Next: a request cadence + Review schema on the site.

Rule: nothing here is "done" until it is either a running system or an open Task with an owner and a next step.
