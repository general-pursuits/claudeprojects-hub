# CONTENT WORKSHOP - wordsmithing + AI/search SEO for website and content

The loop every website page and content piece runs through. Each step names the skill that does it.

## Steps (in order)
1. Angle + audience: the ICP, the buyer's-side POV, the one job the piece does. (product-management:brainstorm;
   od-field-note for articles.)
2. Keyword + AEO research: target terms with REAL volume/difficulty (Semrush free, GSC, live SERP), the
   questions searchers ask, entities to cover. (od-keyword-research; searchfit-seo:content-brief,
   keyword-clustering.) Measured data beats estimates; log every number with its source.
3. Outline to intent: H1/H2s mirror the queries; open every page with a 2-4 sentence extractable answer (AEO);
   plan the FAQ and glossary links.
4. Draft: buyer's-side, plain sentences, one idea each. (opportunity-designed-copy / logan-wordsmith.)
5. Wordsmith pass: voice-scrub, then tighten (fewest words, highest impact; anchor to tagline + core lines;
   no em dashes, no emojis, banned words out).
6. On-page + schema SEO: title <60, meta <155, canonical/OG/Twitter, Article/FAQPage/Person/Org/Service
   JSON-LD, alt text + descriptive filenames, >=3 inbound internal links. (searchfit-seo:on-page-seo,
   schema-markup; od-website-standards.)
7. AI-visibility: earn the citation. Original citable stats, owned vocabulary (performance premium,
   Opportunity Review, Project Fit Call) as glossary/FAQ entries. (od-ai-visibility-tracker; log the money
   prompts.)
8. Gate: od-content-gate + named-entity-check (holds) + proof-bank allowlist for every public claim.
9. Approve + publish: mockup (mobile + web), Addie approves, then WEBSITE-EDIT-PROTOCOL + DEFINITION-OF-DONE
   (the 5 publish points for a field note).
10. Repurpose + measure: od-repurpose to LinkedIn / carousel / newsletter; add to the monthly SEO measurement
    routine.

## Cadence
Monthly: refresh the keyword table (SEO-COMPETITIVE-LANDSCAPE.md), give page-2 movers a title + internal-link
pass, run the AI-visibility log. Follow the priority order in COWORK-GUIDE-marketing-seo.md (BOFU long-tail
first, buyer's-side through-line).
