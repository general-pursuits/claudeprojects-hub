# Opportunity Designed email signature

Open the appropriate file in a browser. Select the rendered signature (not the page source), copy it, and paste it into that email account's signature settings.

- `opportunity-designed-signature.html` is Addie's personal signature for `addie@opportunitydesigned.com`.
- `opportunity-designed-team-signature.html` is the general signature for `hello@opportunitydesigned.com` and is signed by the Opportunity Designed Team.

Both versions include a compact brand lockup using the approved company mark and name.

## Design and compatibility notes

- Brand colors: Obsidian `#1A1714`, Signal Purple `#8E72C6`, Deep Purple `#6B4FA6`, Lavender `#B49CE0`, and muted text `#6B655B`.
- Arial/Helvetica are intentional email-safe substitutes for Inter. Custom web fonts such as Anton and Inter are not consistently supported in email signatures.
- Layout is a simple HTML table with inline styles for Gmail, Outlook, and Apple Mail compatibility.
- The short Signal Purple rule is the only decorative element, keeping the signature lightweight and reliable in email clients.
- Send yourself a test message after installation and check it on desktop and mobile.
