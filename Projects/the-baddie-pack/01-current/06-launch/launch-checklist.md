# Launch Checklist

## Phase 1 — Validate

- [ ] Confirm business name availability in Utah
- [ ] Search federal trademarks and broader web use
- [ ] Check domain and social-handle availability
- [ ] Confirm resident demand through conversations or a small interest form
- [ ] Review direct competitors, pricing, service minimums, and policies
- [ ] Verify building rules for commercial access and solicitation

## Phase 2 — Make the service safe and sellable

- [ ] Select initial services and durations
- [ ] Set service radius and operating hours
- [ ] Calculate capacity, costs, taxes, payment fees, and target income
- [ ] Set prices and cancellation terms
- [ ] Obtain appropriate insurance and bonding if selected or required
- [ ] Complete the chosen background-check verification
- [ ] Prepare service agreement, intake, emergency authorization, and photo consent
- [ ] Establish key/code storage and incident procedures
- [ ] Define severe-weather and unsafe-dog rules

## Phase 3 — Build the client system

- [ ] Create separate business email and phone number
- [ ] Create separate Cal.com identity
- [ ] Configure meet-and-greet requests and approved-client booking
- [ ] Set up payment collection and bookkeeping
- [ ] Create client intake and Walk Report templates
- [ ] Test every confirmation, reminder, reschedule, and cancellation message

## Phase 4 — Build the public presence

- [ ] Build temporary website preview
- [ ] Create visual identity and simple logo system
- [ ] Secure final domain only after name checks
- [ ] Create Instagram profile and initial content set
- [ ] Prepare QR card or resident-safe referral material
- [ ] Avoid publicly sharing live client locations or building access details

## Phase 5 — Pilot

- [ ] Enroll a small number of known or referred clients
- [ ] Require meet and greets
- [ ] Time the entire workflow, not only the walk
- [ ] Collect private feedback
- [ ] Correct policies, pricing, and scheduling friction
- [ ] Ask permission before using any testimonial or dog image

## Phase 6 — Controlled launch

- [ ] Open a limited number of recurring slots
- [ ] Track inquiries, meet-and-greet conversion, repeat bookings, time, and incidents
- [ ] Introduce The Wag List only after recurring capacity is understood
- [ ] Test charms or bandanas as low-cost loyalty rewards before selling merchandise
